# Documentação — Alexandria

Toda a documentação do projeto (raiz, backend e frontend) está centralizada aqui, classificada por tema.

| Pasta | Conteúdo |
|---|---|
| `projeto/` | Visão geral, alinhamento, plano de atividades, user stories, análise do Jira |
| `arquitetura/` | Arquitetura do backend, modelo C4, contrato de API, guia de novos domínios |
| `backend/` | Planos e specs de funcionalidades do backend (perfil, RBAC, auth, user/userbooks) |
| `frontend/` | Fluxos de tela (autenticação, biblioteca, explorar) |
| `leitor/` | Leitor EPUB: progresso de leitura, cálculo de percentual/zoom, cache |
| `banco-de-dados/` | Modelo e ajustes do banco |
| `infraestrutura/` | Ambientes dev/prod, scripts, EventBridge, integração CI/SonarCloud |
| `qualidade/` | Relatórios de teste, análises e correções do SonarCloud |
| `melhorias/` | Propostas de evolução (estúdio de coautoria com IA, chat sobre metadados da biblioteca) |
| `aulas/` | Material acadêmico do projeto integrador |
| `assets/` | Imagens e logs de apoio (`screenshots/`, `leitor/`, `logs/`) |
